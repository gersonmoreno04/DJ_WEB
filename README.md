# 🎧 DJ Events & Booking Platform

Plataforma Web Full-Stack diseñada para la gestión, contratación y reserva de eventos de DJ, con integración de pasarelas de pago y autenticación segura de usuarios.

## 🚀 Características Principales

* **Autenticación y Roles:** Sistema de registro, inicio de sesión seguro mediante tokens (JWT) y control de acceso según el tipo de usuario (Cliente / Administrador).
* **Gestión de Eventos:** Creación, edición y visualización de catálogos de servicios y eventos musicales.
* **Integración de Pagos:** Procesamiento de transacciones en línea integrado de forma segura con **Mercado Pago**.
* **Panel de Control (Dashboard):** Interfaz interactiva para administrar la información de los usuarios y el estado de las reservas.

## 🛠️ Stack Tecnológico

* **Frontend:** [Ej. React.js / HTML5 / CSS3 / Tailwind CSS]
* **Backend:** Node.js, Express.js
* **Base de Datos:** MongoDB / Mongoose
* **Pagos & Seguridad:** API de Mercado Pago, JSON Web Tokens (JWT), Bcrypt
